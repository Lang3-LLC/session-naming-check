    What this is
    A naming audit, not a session audit.
    This reads the Audio track list from Pro Tools' own export and only reports naming. Routing, buses and plugins live in the session itself, not in that text file — so we don't pretend to see them. Naming is where the hours actually go.
    The assistant that fixes this

    What this reads — and what it can't

    Input is the text from File → Export → Session Info as Text. That export contains audio tracks only — aux, bus, folder, VCA, MIDI and instrument tracks are not in it, at any export setting. So this tool cannot judge routing, bus structure or plugin load. It also never writes to your session: the suggestions are text you copy yourself.
